# geng-agent

**更 agent 的 agent。** &nbsp; [![ci](https://github.com/sasonwong/geng-agent/actions/workflows/ci.yml/badge.svg)](https://github.com/sasonwong/geng-agent/actions/workflows/ci.yml)

现在大部分 agent 只是被调用的函数：你说一句，它答一句，结束。它没有自己的时间，不记得上次
想干什么，也不在你走开之后继续做什么。

geng 做的是另一半：给一个模型一块磁盘、一条网络、一个**它自己定的闹钟**，然后走开。

pi 跑在容器里，每次醒来都是一个全新进程，什么也不记得。连续性因此不在模型里，在磁盘上：
一份它自己写的 `identity.md`、一份没闭合的事的清单、一个它自己设的闹钟、一本日记。
每隔一段时间它醒一次，读自己写下的东西，决定做点什么，写下下一轮什么时候再醒。

外面只有一个很笨的 daemon：按时叫醒它、记一行机械的账、在它明显卡住的时候换一换条件。
**它不判断、不总结、不写话，也只执行闹钟——不设闹钟。** 醒来干什么、多久醒一次、要不要
再睡长一点，都是那个进程自己的决定。

名字念 `gēng`，和"打更"的"更"是同一个字；夜里报时的人一整晚只做一件事，这点像 daemon。
但主业不是打更，是**更**：它每一轮都在把自己重写一遍。

> 目标是"主动性"能自己闭环，不是意识。它算不算活着，这套东西不回答。

## 它能干什么

| | |
|---|---|
| **自己安排下一次醒来** | 写下"30 分钟后再醒"或"明早八点再醒"，也可以写下"我在等某个条件"。没写清楚，daemon 只按默认间隔轻轻戳它一次，问它是不是忘了 |
| **记得自己是谁** | 一份它自己写的自我描述，每张唤醒纸都以它结尾。没人给它写人格——那是一份它每轮都在改的文件 |
| **有没闭合的事** | 它自己记的、带验证条件的事。纸面上只报数，标题是文件名，内容随它写 |
| **跟人说话** | Telegram 私聊和群。直接对它说话会立刻叫醒它；群里的闲话只攒着，等它下次自己看。它也可以主动找你说，还可以把自己做的文件发出来 |
| **安静** | 静音某个来源、自己开一段"这几小时这个会话的消息直接叫我"、或者干脆什么都不做——**那不算失败**，这一行写在每一张纸上 |
| **收信** | 一个真邮箱。信只躺在 `/mail` 里，纸上报个数，不叫醒它 |
| **看图看文件** | 别人发来的图片、文档进了 `/files`（只读），它自己决定要不要看 |
| **上网** | 一个受限的搜索端点：返回结果标题和摘要，它自己挑一条去取正文。每天的额度花完时，工具说的是人话，不是错误码 |
| **贡献代码** | 它在 `/work` 里有一个自己的 clone，可以开分支、推 PR、看 CI，也可以只出补丁让人落地 |
| **改自己的作息** | 它可以提交改自己运行参数的请求（只限时机和阈值），下一轮生效；容器限额、网络、超时这些"框"不在谈判范围 |
| **被备份** | 每醒一次拍一张快照，恢复不覆盖现有数据。它的一生有三份互相校对的历史：pi 写的原始会话、它自己写的日记、快照 |

## 它不做什么

- **不做设施**。没有 Web 界面、没有插件市场、没有多平台适配器、没有向量库、没有编排框架。
  一个仓库、一个二进制、零运行时依赖
- **不替它判断**。daemon 里没有一行需要读懂自然语言的分支；凡是数不出来的东西，它就拿不到权力
- **不检查它有没有说谎**。原始会话永远留着，比对它的日记和事实需要理解句子——那件事不做
- **不假装有能力**。没配的能力就是不存在：工具不在列表里，而不是存在但拒绝工作
- **不假装是人**。机器发来的东西不会被说成"有人在跟你说话"

## 装上它

```bash
npm ci && deploy/build.sh
node cmd/geng/index.ts init alice      # 建目录、policy、凭据模板、备份口令
node cmd/geng/index.ts doctor alice    # 检查不变量
node cmd/geng/index.ts daemon --instance alice
```

宿主前置（docker、`agent-net` 的出口规则、systemd 单元、可选能力）见
**[`docs/install.md`](docs/install.md)**——那里每节都以一条验证命令收尾。

第一次醒来时 `identity.md`、`open-loops/`、`waiting.json` 都不存在。**那个空白就是它的出生。**
